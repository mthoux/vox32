# 📻 Vox32 - ESP32 Digital Walkie-Talkie

Vox32 (Contraction of Voice in Latin + 32 from ESP32) is a personal hobby project exploring the idea of a digital walkie-talkie built around an ESP32.

The goal is to create a simple device that can capture audio, send it wirelessly, and receive audio from another unit. The project is still in progress and is mainly a hardware and firmware experiment.

## Hardware

Material used:

- Antenna / radio : NRF24L01 + 3.3V adapter
- Microphone : INMP441
- Amplifier : MAX98357A
- Speaker : 8 Ohm, 1W, 20 mm round
- Controller : ESP32

## Current direction

The architecture is still evolving, and the main difficulty at the moment is that the microphone is not working reliably.

When I'm finished with the prototype, I will look into designing a PCB.
